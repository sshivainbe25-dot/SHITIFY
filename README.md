🎵 Shitify - Spotify Clone

Shitify is a lightweight Spotify-inspired music player that replicates the core experience of a modern music streaming application using pure frontend technologies.

It allows users to browse songs, play/pause music, seek through tracks, and view album artwork in a clean and responsive interface.

✨ Features
🎧 Play and pause songs
⏮️ Previous and Next track controls
📀 Album artwork display
📃 Playlist with song durations
📍 Interactive progress/seek bar
📱 Responsive layout
⚡ Built with Vanilla JavaScript (no frameworks)
🛠️ Tech Stack
HTML5
CSS3
JavaScript (ES6)
